# ARASHIRO — Science Fiction in Ink & Bloom

A Japanese sumi-e-styled landing page for a (fictional) sci-fi author, built
as a scroll-driven story in one self-contained HTML file. Open
`index.html` in any browser.

The blend: ink-wash aesthetics meet science fiction. Branches paint
themselves as you scroll (SVG stroke animation), blossoms are grown
procedurally along the brush paths (a few become stars), falling petals
occasionally streak like meteors, and mid-page the washi paper turns to
night — blossoms become constellations — before returning to cream for
"the cat already knows," where an ink cat watches a tiny rocket ride its
contrail across the sky.

Sections: hero (vertical Japanese accents, hanko seal, scroll hint) →
poem interlude with a stamping seal → three novels with expandable
first-page excerpts → the night turn → the cat → author bio in an ensō
circle → newsletter footer.

All artwork is hand-authored SVG + procedural generation; all copy is
original. The author, the novels, and the excerpts are fictional —
swap in real ones by editing the clearly-labeled sections. Respects
`prefers-reduced-motion`. No external requests, no build step.
