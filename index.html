    Streams JSON frames {"a":[…56 amplitudes]} (or a bare array) into the same pipeline that processes the simulation. Flash the ruvnet/ruview ESP32-S3 CSI firmware and point its sensing server here. Nothing you stream is stored or forwarded.
    How it works. A WiFi channel is measured per OFDM subcarrier (Channel State Information). A chest moving ~5 mm with breath changes the reflected path length, shifting each subcarrier's phase by 2π·Δd/λ — at 5 GHz, λ≈58 mm, so breathing swings the received amplitude measurably and the heartbeat adds a smaller ripple on top. This page simulates that physics (multipath, wall attenuation, noise) and runs a real DSP chain on it: subcarrier selection by variance, sign-aligned aggregation, detrending, band-pass isolation and windowed FFT peak estimation for vitals, streaming deviation statistics for motion/presence, phase-acceleration heuristics for falls, and per-link energy matching for coarse localization. The identical pipeline accepts a live ESP32 CSI stream. Modeled on ruvnet/ruview (MIT). Privacy: no cameras, no wearables, no accounts, no cookies, no storage of any kind, and no network requests — every buffer lives in RAM for this tab and vanishes when you close it.
